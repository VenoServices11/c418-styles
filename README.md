# C418 Styles files

The style packs, previews and sky pictures for the Styles menu in C418 Client.
The client ships with `index.json` and downloads a pack (and its preview) the first time it is picked.

- `index.json` - every style: id, collection, name, SHA-256, size
- `packs/` - the packs
- `previews/` - the menu pictures
- `blobs/` - big sky pictures, stored once and shared between skies
